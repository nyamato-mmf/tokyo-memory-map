# Tokyo Memory Map — Python / Web 自動連携版

歴史写真の撮影場所・撮影年（または年代）をPython / Jupyter Notebookで整理し、処理済みの写真とメタデータをWebサイト側に直接保存する構成です。

## 基本フロー

1. 未整理のスキャン写真を `_python/unidentified/` に入れる
2. `_python/01_shooting_location_year.ipynb` を起動する
3. 写真を確認し、地図をクリックして撮影地点を指定する
4. 「特定年」または「撮影年代」を選択する
5. 必要に応じてタイトル・説明・市区町村を入力する
6. 「A：緯度経度＋年/年代を保存」を押す
7. 写真はWeb公開用の `photo/` に移動する
8. メタデータは `data/photos.json` に自動保存される
9. Webサイトは `data/photos.json` を読み込み、地図・一覧・詳細・拡大表示に反映する

### 市区町村までしか分からない写真

「B：市区町村へ移動」を使うと、写真は次の場所へ移動します。

```text
_python/unidentified/{市区町村}/
```

元のファイル名は変更しません。

### まだ判断できない写真

「C：スキップ」を押すと、写真は `_python/unidentified/` に残ります。

## フォルダ構成

```text
tokyo-memory-map/
├─ _python/
│  ├─ unidentified/              # 未整理・保留写真
│  │  └─ {市区町村}/              # 市区町村だけ判明した写真
│  └─ 01_shooting_location_year.ipynb

│  └─ 35.672100_139.765000_1978.jpg
```

## 写真ファイル名

処理時には原則として次の形式で保存します。

```text
緯度_経度_撮影年または年代.拡張子
```

例：

```text
35.672100_139.765000_1978.jpg
35.672100_139.765000_1970-1979.jpg
```

同じ名前が既に存在する場合は `_001`, `_002` のような連番を付けます。

## Webサイトの起動

プロジェクトのルートディレクトリで以下を実行してください。

```bash
python -m http.server 8000
```

その後、ブラウザで `http://localhost:8000/` を開きます。

`index.html` を直接ダブルクリックして `file://` で開くと、JSON読み込みがブラウザのセキュリティ制約で動作しない場合があります。

## Notebookについて

Notebookは、カーネルの現在位置がプロジェクトルートでも `_python/` でも動作するようにプロジェクトルートを判定します。

必要なPythonパッケージ：

```bash
pip install ipywidgets ipyleaflet pillow
```

## Web側の自動反映

Webサイトは `data/photos.json` を読み込みます。ページを開いたままNotebookで写真を追加すると、一定間隔でJSONを再読込して地図・写真一覧を更新します。

## 販売機能

写真の拡大表示には「この写真を購入する」ボタンを設置しています。現在は購入処理のUIのみで、決済・注文フォーム・ライセンス管理などは今後接続する想定です。


## 画像の保存対策

Webサイト上の写真について、画像上の右クリック、ドラッグ、選択操作を抑止しています。これはカジュアルな保存操作を防ぐための対策です。

ただし、Webブラウザに配信された画像を完全に保存不能にすることはできません。販売用の高解像度原版を保護する場合は、Web公開用には低解像度・透かし入りのプレビュー画像を使用し、購入後にのみ原版を提供する構成を推奨します。
